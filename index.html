그룹 관리

동기화 설정

이 브라우저에서 그룹을 편집하면 GitHub 저장소의 data/groups.json에 자동 커밋됩니다. 다른 기기에서 사이트를 열면 같은 그룹이 자동으로 로드돼요.

현재 상태
—

1. GitHub Personal Access Token 만들기

  1. 여기 클릭 → Fine-grained PAT 만들기 페이지 열림
  2. Token name: jyfund-signal-sync
  3. Expiration: 원하시는 기간 (권장: 1년)
  4. Resource owner: thehfk
  5. Repository access: Only select repositories → jyfund-signal 선택
  6. Permissions → Repository permissions → Contents: Read and write 로 설정
  7. Generate token → 만들어진 토큰(github_pat_...) 복사

2. 여기 붙여넣기

토큰은 이 브라우저의 localStorage에 저장되며, GitHub API 외 다른 서버로 전송되지 않습니다. 다른 사람이 이 브라우저에 접근할 수 있으면 삭제해 주세요.

주의사항

  • GitHub Pages는 캐시가 있어서 다른 기기에 반영까지 최대 5~10분 걸릴 수 있습니다.
  • 두 기기에서 동시에 편집하면 나중 편집이 이깁니다 (충돌 시 자동 재시도).

Universe · Group 개념

Universe = 파이썬이 30분마다 스캔하는 전체 종목 풀 (data/universe.json). 지금 47개.

Group = 브라우저에 저장되는 내 관심 리스트. 그룹을 바꾸면 같은 스캔 결과에서 다른 종목만 골라서 보여줍니다.

Universe에 없는 티커는 그룹에 넣어도 스캔되지 않습니다. 스캔하려면 data/universe.json에 추가하고 commit (Phase 2에서 웹 UI 예정).
